# Verified 4ZQK target artifact

This directory contains the experimental PDB coordinates and a reproducible geometric contact map.

- Chain A: PD-L1 (Programmed cell death 1 ligand 1)
- Chain B: PD-1 (Programmed cell death protein 1)
- Contact definition: any non-hydrogen ATOM pair across chains within 4.5 Angstrom
- Interface residues found on PD-L1: 18
- Source: https://www.rcsb.org/structure/4ZQK

The contact map is structural evidence, not a functional hotspot assay. Use the accompanying notebook to reproduce it and preserve the exact chain mapping before RFdiffusion.
